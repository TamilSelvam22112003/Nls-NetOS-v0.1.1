# Nls-NetOS-v0.1.1

Ubuntu router agent for NLS: enrollment client, authenticated control connection, TUN/packet selection, NLS handshake and encrypted data plane. **Status: specification/scaffolding only; not operational or production-ready.** No v0.1.0 code is used.

See docs/ARCHITECTURE.md, docs/PROTOCOL.md, docs/THREAT_MODEL.md, docs/TEST_PLAN.md and docs/ROADMAP.md. The Core repository's protocol contract is normative.
